# Michela De Buono Filippelli

Portfolio di teatro, regia e arte.

Sito: https://m-dbf.github.io/portfolio/

Sito statico in HTML, CSS e JavaScript. Le immagini WebP e gli estratti video Full HD ottimizzati sono inclusi localmente, senza dipendenze da installare o servizi video esterni obbligatori.

## Contenuti

- `contenuti.js`: progetti, testi, crediti e percorsi dei materiali.
- `video.config.js`: collegamenti opzionali Vimeo, YouTube o MP4 HTTPS. Lasciandoli vuoti vengono usati gli estratti inclusi.
- `assets/web`: immagini complete e anteprime responsive.
- `assets/video-web`: estratti video H.264/AAC con avvio progressivo.
- `assets/fonts`: font con le relative licenze.

GitHub Pages è configurato per il ramo `main`, cartella radice. La navigazione usa percorsi relativi, quindi funziona sotto `/portfolio/`.

## Diritti e font

Non è assegnata una licenza open source al codice e ai materiali artistici di questo portfolio. I contenuti conservano i diritti dei rispettivi titolari. I font Inter e Instrument Serif sono distribuiti secondo le licenze OFL incluse in `assets/fonts`.
